# NexaKeyboard — সংস্করণ v2.2 (Gboard-ধাঁচের দেখতে + বাংলা কি)

বাংলা (বিজয়) + ইংরেজি অ্যান্ড্রয়েড কীবোর্ড, Kotlin-এ লেখা।
মুরাদের জন্য বানানো — নাম **NexaKeyboard**, বাংলা টাইপিং **বিজয়**।

NexaKeyboard v2.2 — Bangla (Bijoy) + English Android keyboard in Kotlin,
built for Murad. Gboard-like look, Bengali keys, no glide typing.

## v2.2 — বাংলা কি, দুই দিকের ি, ক্লিপবোর্ড প্রিভিউ, সেটিংস আইকন

- **বাংলা কি-তে বাংলা অক্ষর:** বাংলা মোডে এখন কি-গুলোতে বাংলা অক্ষরই
  দেখায় — যেমন ক-র কি-তে **ক**, খ-র কি-তে **খ** (Gboard-এর বাংলা
  লেআউটের মতো)। দেখে দেখে বসানো যায়, ইংরেজি অক্ষর দেখে আন্দাজ করতে
  হয় না। Shift চাপলে Shift-এর বাংলা অক্ষর দেখায় (যেমন খ, ঢ, ণ)।
  টাইপিংয়ের নিয়ম বদলায়নি — ভেতরে এখনো বিজয় ম্যাপিংই চলে।
  ইংরেজি মোডে কি-তে ইংরেজি অক্ষরই থাকে।
- **ি / ে / ৈ — দুই দিকেই চলে:** বিজয়ের মতো আগে চাপলেও হবে (ি তারপর ক
  = কি), আবার Gboard-এর মতো পরেও চাপা যাবে (ক তারপর ি = কি)।
  ব্যঞ্জনবর্ণের পরে চাপলে চিহ্নটা সঙ্গে সঙ্গে বসে যায়; ব্যঞ্জনবর্ণ
  না থাকলে আগের মতো পরের ব্যঞ্জনবর্ণের জন্য ধরে রাখা হয়।
  ো স্বাভাবিকভাবেই হয় (ে + ব্যঞ্জনবর্ণ + া = ো)।
- **ক্লিপবোর্ড প্রিভিউ সাজেশন বারে:** যেকোনো অ্যাপে কিছু কপি করলেই
  সাজেশন বারের শুরুতে কপি করা লেখাটার ছোট প্রিভিউ দেখাবে (প্রথম
  ~২০ অক্ষর, বেশি হলে … দিয়ে)। চাপলে পুরো লেখাটা বসে যাবে। কপি করা
  কিছু না থাকলে চিপটা লুকিয়ে থাকে, স্বাভাবিক ৩টা শব্দের সাজেশনই
  থাকে।
- **⚙️ সেটিংস আইকন:** টুলবারে ⚙️ আইকন আছে — চাপলেই কীবোর্ড থেকে
  সরাসরি NexaKeyboard সেটিংস খুলবে, অ্যাপ আইকন খুঁজে খুলতে হবে না।
  সেটিংসে টুলবার এডিটর থেকে এটাকে রিঅর্ডার করা যায়, আর লুকিয়ে
  ফেললেও অ্যাপ আইকন দিয়ে সেটিংস খোলা যাবে।

## v2.1 — Gboard-ধাঁচের দেখতে / Gboard-like look

- **Gboard-এর রং:** ডার্ক থিমে কীবোর্ডের ব্যাকগ্রাউন্ড #202124, কি #303134,
  বিশেষ কি #5F6368, লেখা #E8EAED; লাইট থিমে ব্যাকগ্রাউন্ড #F1F3F4, কি সাদা,
  বিশেষ কি #DADCE0। সাজেশনের লেখা Gboard নীল (#8AB4F8 / #1A73E8),
  Enter কি নীল। পুরনো সবুজ অ্যাকসেন্ট আর নেই।
- **গোল কি:** কি-র কোণা 10dp গোল, কি-গুলোর মাঝে একটু বেশি ফাঁকা জায়গা,
  অক্ষরের লেখা 22sp — Gboard-এর মতো হালকা আর পরিষ্কার দেখায়।
- **একটা চিকন টুলবার:** আগের দুই সারির বদলে একটাই 36dp চিকন সারি —
  টুলবারের বোতামগুলো সমতল (কীবোর্ডের ব্যাকগ্রাউন্ডের মতো, ধূসর বাক্স নয়)।
  শব্দের সাজেশন তার নিচে আলাদা সারিতে, মাঝখানে, নীল রংয়ে।
- **টুলবার আইকন-শুধু:** কোনো বোতামে লেখা নেই — Grammar Fix ✎, Tone 🎭,
  Clipboard 📋, Phrases 💬, Paste 📥, Undo ↩, Redo ↪, Settings ⚙️।
  সেটিংসে (৬. টুলবার) প্রতিটা আইটেমের টিক চিহ্ন দিয়ে দেখানো/লুকানো যায় আর
  Up / Down দিয়ে ক্রম বদলানো যায় — কীবোর্ডে শুধু দেখানো আইটেমগুলোই
  সেভ করা ক্রমে দেখাবে। ডিফল্টে সবগুলোই দেখানো থাকে। v2.2-এ ⚙️
  চাপলে কীবোর্ড থেকেই সেটিংস খুলে যায়।
- **স্পেসবার:** বড় "স্পেস" লেখার বদলে ছোট করে বর্তমান ভাষার নাম দেখায় —
  বাংলা মোডে "বাংলা", ইংরেজিতে "English"।
- **নাম্বার সারি:** বাংলা সংখ্যার সারি আগের মতোই আছে, তবে চিকন —
  অন্যান্য সারির সমান উচ্চতা, সংখ্যার লেখা 18sp। সেটিংসে "Number row
  দেখান" বন্ধ করলে সারিটা লুকিয়ে যাবে, তখন দেখতে ঠিক Gboard-এর মতো হবে।
- **সীমা:** কি-গুলো GradientDrawable দিয়ে আঁকা হয়, তাই Gboard-এর মতো
  আসল ছায়া (elevation/shadow) এতে নেই — রং আর আকার দিয়েই মিল আনা হয়েছে।

## যা আছে / What is included

### v1 থেকে (অপরিবর্তিত)
- বাংলা বিজয় কীবোর্ড — ইউনিকোড লেআউট (কি = `d` তারপর `j`, কে = `c` তারপর `j`)
- ইংরেজি QWERTY কীবোর্ড — এক ট্যাপে ভাষা বদল (`বাং` / `EN`)
- বাংলা সংখ্যা (১–৯, ০) — বিজয় মোডে
- শব্দের সাজেশন (ছোট তালিকা থেকে) — সাজেশনে ট্যাপ করলে শব্দ বসে যায়
- ইমোজি কীবোর্ড (৪৮টা), নাম্বার আর সিম্বল (`?123`, ৳ সহ)
- ডার্ক / লাইট থিম — Gboard-ধাঁচের রং
- যুক্তবর্ণ: হসন্ত (`g`) দিয়ে — ক্ত = `j` `g` `k`, কর্ম = `j` `Shift+a` `m`

### v2-তে নতুন
- **ভয়েস টাইপিং** — কীবোর্ডের 🎤 বোতাম। বাংলা মোডে bn-BD, ইংরেজি মোডে
  en-US দিয়ে Android SpeechRecognizer চলে। Gemini API কী থাকলে ভয়েসের
  লেখাটা AI দিয়ে রিফাইন হয় (বানান/দাঁড়ি-কমা ঠিক, "um"-এর মতো ফিলার
  বাদ); কী না থাকলে আসল লেখাটাই বসে। কিছু শোনা না গেলে বা ভুল হলে
  টোস্ট দেখায়, অ্যাপ ক্র্যাশ করে না।
- **Gemini API কী (সেটিংসে)** — অ্যাপ ইনস্টল করার পরে
  NexaKeyboard অ্যাপ > Gemini API কী-তে কী বসানো যায়, পরে Save / Update
  দিয়ে বদলানো যায়, Clear দিয়ে মোছা যায়। Test বোতাম শুধু দেখে কী
  সেভ করা আছে কিনা — এতে কোনো নেটওয়ার্ক কল হয় না। পুরো কী কখনো
  স্ক্রিনে দেখানো হয় না, শুধু "saved" / "not set" লেখা থাকে। কী-টা
  শুধু ফোনের SharedPreferences-এ থাকে, কোডে লেখা থাকে না।
- **Grammar Fix** — কীবোর্ডের ✎ বোতাম। কার্সরের আগের বাক্যটা Gemini-কে
  পাঠায়, শুধু ব্যাকরণ/বানান/দাঁড়ি-কমা ঠিক করে, অর্থ বদলায় না।
- **Tone Change** — সেটিংসে Tone বাছুন: Professional / Casual /
  Formal / Friendly। কীবোর্ডের Tone বোতাম সেই ভঙ্গিতে বাক্যটা সাজায়।
- **টুলবার: Paste / Undo / Redo** — v2.1-এ এগুলো আর সাজেশনের পাশে নয়,
  উপরের একটাই চিকন আইকন-শুধু টুলবারে থাকে (📥 / ↩ / ↪)। সেটিংসে
  Up / Down দিয়ে এদের ক্রম বদলানো যায়, টিক চিহ্ন দিয়ে লুকানো যায়।
- **Undo / Redo-র সীমা** — শেষ ২০টা এডিটের স্ন্যাপশট রাখা হয়,
  প্রতিটা কার্সরের আগের সর্বোচ্চ ৫০০ অক্ষর। কার্সরের পরের লেখা
  Undo/Redo ছোঁয় না।
- **ক্লিপবোর্ড হিস্ট্রি** — 📋 বোতামে শেষ ১০টা কপি করা লেখা দেখা যায়,
  ট্যাপ করলে বসে যায়। Paste করলে বা Clipboard প্যানেল খুললে বর্তমান
  ক্লিপবোর্ডের লেখাটা হিস্ট্রিতে যোগ হয়।
- **Quick Phrases** — সেটিংসে যোগ/মুছে ফেলা যায়। শুরুতে ৩টা আছে:
  `ছয়গাঁও ফার্মেসি`, `ধন্যবাদ`, `আসসালামু আলাইকুম`। কীবোর্ডের
  Phrases বোতামে ট্যাপ করলে ফ্রেজটা বসে যায়।
- **প্রতি ভাষায় আলাদা অটোকারেক্ট** — সেটিংসে আলাদা সুইচ:
  Autocorrect Bangla (ডিফল্ট: বন্ধ), Autocorrect English (ডিফল্ট: চালু)।
- **থিম এডিটর** — Light / Dark, কি-র রং ৩টা প্রিসেট (Gboard grey /
  Dark / Blue), কি-র আকার (Rounded / Square), কীবোর্ডের উচ্চতা
  (Short / Medium / Tall)।

## Gemini API কী বসানো / বদলানো (ইনস্টলের পরে)

১. NexaKeyboard অ্যাপ খুলুন।
২. "২. Gemini API কী" অংশে কী-টা লিখুন।
৩. **Save / Update** চাপুন — নিচে "API key: saved" লেখা আসবে।
৪. বদলাতে চাইলে নতুন কী লিখে আবার **Save / Update** চাপুন।
৫. মুছতে চাইলে **Clear** চাপুন।
৬. **Test** চাপলে শুধু দেখাবে কী সেভ করা আছে কিনা — এতে ইন্টারনেট
   বা Gemini-তে কোনো কল যায় না।

কী ছাড়া ভয়েস টাইপিং, Grammar Fix আর Tone Change-এর AI অংশ চলবে
না — তখন "Gemini API key needed — set it in NexaKeyboard settings"
টোস্ট দেখাবে, আর ভয়েসের ক্ষেত্রে আসল লেখাটাই বসবে।

## ভয়েস টাইপিং ব্যবহার

১. বাংলা লিখতে চাইলে বাংলা মোডে, ইংরেজি চাইলে ইংরেজি মোডে যান।
২. কীবোর্ডের 🎤 বোতাম চাপুন, তারপর বলুন।
৩. Gemini কী থাকলে লেখাটা পরিষ্কার হয়ে বসবে, না থাকলে যেমন শোনা
   গেছে তেমনই বসবে।

## APK বানানো (Android Studio দিয়ে)

১. Android Studio খুলে **Open** দিয়ে এই `NexaKeyboard` ফোল্ডারটা খুলুন।
২. প্রথমবার ইন্টারনেট লাগবে — Gradle আর Android SDK ডাউনলোড হবে।
৩. উপরে **Run ▶** চাপুন (ফোন USB দিয়ে লাগানো থাকলে) অথবা
   **Build → Build App Bundle(s) / APK(s) → Build APK(s)**।
৪. APK পাবেন `app/build/outputs/apk/debug/app-debug.apk`-এ।
৫. প্রথমবার ভয়েস টাইপিং ব্যবহারের সময় ফোন মাইক্রোফোনের অনুমতি চাইবে।

## ফোনে চালু করা

১. APK ইনস্টল করুন।
২. NexaKeyboard অ্যাপ খুলে **কীবোর্ড চালু করুন** চাপুন — সেটিংসে গিয়ে
   NexaKeyboard অন করুন।
৩. **কীবোর্ড বেছে নিন** চাপুন — তালিকা থেকে NexaKeyboard বেছে নিন।
৪. যেকোনো জায়গায় লিখে দেখুন।

## সৎ সীমা / Honest limits

- এই পরিবেশে Android SDK নেই, তাই **APK এখানে কম্পাইল করে দেখা
  যায়নি** — Android Studio দিয়ে বানাতে হবে।
- ভয়েস টাইপিংয়ের জন্য ইন্টারনেট আর ফোনে Google-এর স্পিচ সার্ভিস
  লাগবে; না থাকলে "এই ফোনে ভয়েস টাইপিং পাওয়া যাচ্ছে না" দেখাবে।
- Gemini কলগুলোর জন্য ইন্টারনেট আর বৈধ API কী লাগবে; Gemini-র
  দাম তাদের নিজের প্রাইসিং অনুযায়ী হতে পারে, কল ব্যর্থ হলে আসল
  লেখাটাই বসে।
- গ্লাইড টাইপিং নেই।
- Undo/Redo শুধু কার্সরের আগের লেখায় কাজ করে, শেষ ২০টা এডিট
  পর্যন্ত, প্রতিটা সর্বোচ্চ ৫০০ অক্ষর।
