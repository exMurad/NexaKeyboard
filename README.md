# NexaKeyboard — সংস্করণ v2.4 (মাইক ঠিক, ছোট কীবোর্ড, পরিষ্কার Gemini কী)

বাংলা + ইংরেজি অ্যান্ড্রয়েড কীবোর্ড, Kotlin-এ লেখা।
মুরাদের জন্য বানানো — নাম **NexaKeyboard**।

NexaKeyboard v2.4 — Bangla + English Android keyboard in Kotlin,

## v2.4 — মাইক অনুমতি, ছোট কীবোর্ড, পরিষ্কার Gemini কী

- **মাইক আর ক্লিক করলেই ফেল করবে না:** আসল কারণ ছিল —
  মাইকের অনুমতি (RECORD_AUDIO) ম্যানিফেস্টে লেখা থাকলেও কোডে
  কখনো চাওয়া হয়নি, তাই ভয়েস টাইপিং শুরু হওয়ার সঙ্গে সঙ্গে
  "অনুমতি নেই" এররে বন্ধ হয়ে যেত। এখন সেটিংস খুললেই অনুমতি
  চাওয়া হয়, আর সেটিংসের একদম উপরে একটা বড় সারিতে সবসময়
  দেখায় — সবুজ "মাইক্রোফোন: অনুমতি দেওয়া হয়েছে ✓" অথবা লাল
  "মাইক্রোফোন: অনুমতি দেওয়া হয়নি" + [অনুমতি দিন] বোতাম।
  অনুমতি না থাকলে মাইক চাপলে Toast-এ পরিষ্কার বলে ("মাইকের
  অনুমতি দেওয়া হয়নি — NexaKeyboard অ্যাপ খুলে অনুমতি দিন") আর
  সেটিংস খুলে দেয়, চুপচাপ ফেল করে না। ভয়েসের live ফিডব্যাকও
  এখন আসলেই আসে — partial result এখন সত্যিই চাওয়া হয়।
- **কীবোর্ড আর পুরো ডিসপ্লে ঢাকবে না:** কি-র উচ্চতা কমানো হয়েছে
  — Short ৪০ / Medium ৪৬ / Tall ৫২ dp (আগে ৪৬ / ৫৪ / ৬২), আর
  ডিফল্ট এখন **Short** (আগে Medium ছিল)। টুলবারের সারিও
  ৩৬dp থেকে ৩২dp করা হয়েছে। Short-এ ৭ সারির কি-র জায়গা এখন
  ~৩২২dp — আগের ~৪২০dp-র বদলে, মোট উচ্চতা ~১০০dp কম।
  সেটিংসে Short / Medium / Tall বেছে নেওয়া যায় আগের মতোই।
- **Gemini কী — সেভ/টেস্ট আর মিস করা যাবে না:** কী-র সেকশনটা
  এখন সেটিংসের একদম উপরে (আগে লম্বা স্ক্রিনের মাঝখানে হারিয়ে
  যেত)। বড় (১৮sp, বোল্ড) রঙিন স্ট্যাটাস লাইন: সেভ হলে সবুজ
  "✓ সেভ হয়েছে — শেষ ৪ অক্ষর: XXXX", না থাকলে লাল "এখনো কোনো
  কী দেওয়া হয়নি"। Save চাপলে সঙ্গে সঙ্গে স্ট্যাটাস বদলায় আর
  Toast-এ শেষ ৪ অক্ষরসহ জানায়। Test-এর ফলাফলও ওই বড় লাইনেই
  থাকে (সবুজ "Test passed ✓" / লাল "Test failed: কারণ")।
- **ভয়েস টাইপিংয়ে কোনো বিপ (beep) নেই:** ভয়েস শোনা শুরু হলে
  recognizer সার্ভিস একটা বিপ বাজায়, আর অনেক কীবোর্ডে শোনার
  সময় বারবার বিপ হয়। NexaKeyboard শোনা শুরুর আগেই ফোনের
  ওই সাউন্ডগুলো চুপ করিয়ে দেয় (মিউজিক / নোটিফিকেশন /
  সিস্টেম স্ট্রিম mute করে), আর শোনা শেষ হলেই (ফলাফল আসলে,
  ভুল হলে, বা কীবোর্ড বন্ধ হলে) আবার আগের মতো করে দেয় —
  ফোনের স্বাভাবিক সাউন্ড কখনো mute হয়ে থাকে না। ভয়েস
  টাইপিং তাই পুরোপুরি নীরবে চলে, ৫ সেকেন্ড পর পর বিপ হয় না।
- **ভুল কী বসালে সতর্কবার্তা:** আসল Gemini API কী "AIza" দিয়ে
  শুরু হয়। "AIza" দিয়ে শুরু না হওয়া কী সেভ করলে (যেমন
  "AQ.Ab8R" দিয়ে শুরু হওয়া কী) লাল সতর্ক লাইন দেখায় —
  "এটা Gemini API কী মনে হচ্ছে না — Google AI Studio থেকে
  'AIza' দিয়ে শুরু হওয়া কী নিন" — কী-টা তবু সেভ হয়, আটকানো
  হয় না। "AI Studio থেকে কী নিন" বোতাম চাপলে
  aistudio.google.com খোলে, সেখান থেকে সঠিক কী নেওয়া যায়।
  Test বোতাম আগের মতোই সত্যিই Gemini-কে ডাকে, ব্যর্থ হলে আসল
  কারণ দেখায় (Invalid API key / No internet / Quota)।

## v2.3 — ফ্ল্যাট Gboard লেআউট, সরাসরি বাংলা বর্ণমালা

- **সম্পূর্ণ ফ্ল্যাট কি (Gboard-এর মতো):** অক্ষরের কি-তে এখন আর কোনো
  ধূসর বাক্স/বর্ডার নেই — ডার্ক থিমে (#202124) শুধু হালকা অক্ষর,
  লাইট থিমে (#F1F3F4) শুধু গাঢ় অক্ষর। শুধু স্পেসবারটা ধূসর গোল
  (pill) আর Enter কি-টা নীল গোল। মুরাদের Gboard স্ক্রিনশটের মতোই।
- **সরাসরি বাংলা লেআউট (ডিফল্ট):** বাংলা মোডে এখন Gboard-এর বাংলা
  কীবোর্ডের মতো সরাসরি বর্ণমালা — বিজয় QWERTY ম্যাপিং নয়:
  অ আ ই ঈ উ ঊ এ ঐ ও ঔ / ক খ গ ঘ ঙ চ ছ জ ঝ ঞ / ট ঠ ড ঢ ণ ত থ দ ধ ন /
  প ফ ব ভ ম য র ল শ ষ / স হ ড় ঢ় য় ৎ ং ঃ। কি চাপলেই সেই বাংলা
  অক্ষরটা বসে যায়, দেখে দেখে বসানো যায়।
- **Shift লেয়ার (স্বরচিহ্ন):** বাংলা মোডে Shift (⇧) চাপলে স্বরচিহ্ন
  আর যুক্তবর্ণের সারি আসে — া ি ী ু ূ ৃ ে ৈ ো ৌ / ্ র্ ্য ্র ্‌ল
  ঁ ং ঃ ৎ । / ক্ষ জ্ঞ ত্র শ্র দ্র দ্ধ ন্ত স্ত ন্দ ঙ্ক / ১–০ /
  ? ! , . - ৳ % ( )। যুক্তবর্ণ: ্ তারপর ব্যঞ্জনবর্ণ (ক + ্ + ত = ক্ত)।
  ি/ে/ৈ ব্যঞ্জনবর্ণের পরে চাপলে সঙ্গে সঙ্গে বসে (ক + ি = কি)।
- **কি-র উপরে ছোট চিহ্ন (Gboard-এর মতো):** প্রতিটা কি-র উপরের
  কোণায় একটা ছোট (৯sp) ধূসর বিকল্প চিহ্ন থাকে — ইংরেজিতে q-তে ১,
  w-তে ২, a-তে @, s-তে # (Gboard-এর মতো); বাংলায় ক-তে া, খ-তে ি,
  গ-তে ু। চাপলে বড় অক্ষরটা বসে, **লং-প্রেস করলে ছোট চিহ্নটা বসে**।
  বিজয় লেআউটে ছোট চিহ্ন হিসেবে QWERTY অক্ষরটা দেখায় (যেমন ক-তে j)।
- **Bijoy লেআউট এখনো আছে:** সেটিংসে "বাংলা লেআউট" থেকে Bijoy
  QWERTY বাছলে আগের মতো ইংরেজি কি-তে বিজয় টাইপিং চলবে
  (কি = d তারপর j, কে = c তারপর j)।
- **মাইক এখন উপরে ডানদিকে:** 🎤 বোতাম আর নিচের সারিতে নেই —
  Gboard-এর মতো উপরের টুলবারের একদম ডানদিকে থাকে। চাপলেই আগের
  মতো ভয়েস টাইপিং শুরু হয়। নিচের সারি এখন: ?১২৩, 🌐, 😀,
  স্পেসবার, ।, নীল Enter — ঠিক Gboard-এর মতো।
- **হোল্ড-টু-ডিলিট:** ⌫ চাপ দিয়ে ধরে রাখলে Gboard-এর মতো একটানা
  অক্ষর ডিলিট হতে থাকে — প্রথমে একটা, ৪০০ মিলিসেকেন্ড পরে প্রতি
  ৬০ মিলিসেকেন্ডে একটা করে, আঙুল তুললেই থেমে যায়। হালকা একটা
  ট্যাপে ঠিক একটাই অক্ষর ডিলিট হয়।
- **Gemini কী — সেভ/টেস্টে স্পষ্ট ফলাফল:** Save চাপলে Toast-এ
  "Gemini API key saved ✓" আসে, আর স্ট্যাটাস লাইনে বড় করে দেখায়
  "API key: saved ✓ (…শেষ ৪ অক্ষর)" — পুরো কী কখনো দেখায় না।
  Clear করলে "API key removed" আর স্ট্যাটাস "API key: not set"।
  **Test বোতাম এখন সত্যিই Gemini-কে ডাকে** ("Say OK" পাঠায়) —
  চলার সময় বোতাম বন্ধ থাকে আর "Testing…" দেখায়; সফল হলে
  "Test passed ✓ — Gemini is working" (উত্তরসহ), ব্যর্থ হলে আসল
  কারণ দেখায় — যেমন "Invalid API key", "No internet",
  "Quota exceeded"। কোনো টেস্টেই ফলাফল ছাড়া থাকা যায় না।
- **ভয়েস টাইপিংয়ে অবস্থা দেখায়:** মাইক চাপলে সাজেশন বারের
  মাঝখানে "🎤 শুনছি…" দেখায়, বলার সময় শোনা কথাটা সরাসরি
  (live) দেখায়, Gemini রিফাইন করার সময় "AI ঠিক করছে…" দেখায়,
  তারপর পরিষ্কার লেখাটা বসে। AI ব্যর্থ হলে আসল লেখাটাই বসে আর
  কারণসহ Toast আসে। ভুল হলে কারণটা নির্দিষ্ট করে বলে — কিছু
  শোনা যায়নি / ইন্টারনেট নেই / মাইকের অনুমতি নেই। কী না থাকলে
  ভয়েসের আসল লেখাটাই বসে (Gemini কল হয় না)।
- **নিচের সারি:** ভাষা বদলাতে এখন 🌐 (গ্লোব) আইকন — চাপলেই বাংলা/
  ইংরেজি বদলায়; বর্তমান ভাষা স্পেসবারে ছোট করে লেখা থাকে
  ("বাংলা" / "English")।

## v2.2 — বাংলা কি, দুই দিকের ি, ক্লিপবোর্ড প্রিভিউ, সেটিংস আইকন

- **বাংলা কি-তে বাংলা অক্ষর:** বাংলা মোডে এখন কি-গুলোতে বাংলা অক্ষরই
  দেখায় — যেমন ক-র কি-তে **ক**, খ-র কি-তে **খ** (Gboard-এর বাংলা
  লেআউটের মতো)। দেখে দেখে বসানো যায়, ইংরেজি অক্ষর দেখে আন্দাজ করতে
  হয় না। Shift চাপলে Shift-এর বাংলা অক্ষর দেখায় (যেমন খ, ঢ, ণ)।
  টাইপিংয়ের নিয়ম বদলায়নি — ভেতরে এখনো বিজয় ম্যাপিংই চলে।
  ইংরেজি মোডে কি-তে ইংরেজি অক্ষরই থাকে।
- **ি / ে / ৈ — দুই দিকেই চলে:** বিজয়ের মতো আগে চাপলেও হবে (ি তারপর ক
  = কি), আবার Gboard-এর মতো পরেও চাপা যাবে (ক তারপর ি = কি)।
  ব্যঞ্জনবর্ণের পরে চাপলে চিহ্নটা সঙ্গে সঙ্গে বসে যায়; ব্যঞ্জনবর্ণ
  না থাকলে আগের মতো পরের ব্যঞ্জনবর্ণের জন্য ধরে রাখা হয়।
  ো স্বাভাবিকভাবেই হয় (ে + ব্যঞ্জনবর্ণ + া = ো)।
- **ক্লিপবোর্ড প্রিভিউ সাজেশন বারে:** যেকোনো অ্যাপে কিছু কপি করলেই
  সাজেশন বারের শুরুতে কপি করা লেখাটার ছোট প্রিভিউ দেখাবে (প্রথম
  ~২০ অক্ষর, বেশি হলে … দিয়ে)। চাপলে পুরো লেখাটা বসে যাবে। কপি করা
  কিছু না থাকলে চিপটা লুকিয়ে থাকে, স্বাভাবিক ৩টা শব্দের সাজেশনই
  থাকে।
- **⚙️ সেটিংস আইকন:** টুলবারে ⚙️ আইকন আছে — চাপলেই কীবোর্ড থেকে
  সরাসরি NexaKeyboard সেটিংস খুলবে, অ্যাপ আইকন খুঁজে খুলতে হবে না।
  সেটিংসে টুলবার এডিটর থেকে এটাকে রিঅর্ডার করা যায়, আর লুকিয়ে
  ফেললেও অ্যাপ আইকন দিয়ে সেটিংস খোলা যাবে।

## v2.1 — Gboard-ধাঁচের দেখতে / Gboard-like look

- **Gboard-এর রং:** ডার্ক থিমে কীবোর্ডের ব্যাকগ্রাউন্ড #202124, কি #303134,
  বিশেষ কি #5F6368, লেখা #E8EAED; লাইট থিমে ব্যাকগ্রাউন্ড #F1F3F4, কি সাদা,
  বিশেষ কি #DADCE0। সাজেশনের লেখা Gboard নীল (#8AB4F8 / #1A73E8),
  Enter কি নীল। পুরনো সবুজ অ্যাকসেন্ট আর নেই।
- **গোল কি:** কি-র কোণা 10dp গোল, কি-গুলোর মাঝে একটু বেশি ফাঁকা জায়গা,
  অক্ষরের লেখা 22sp — Gboard-এর মতো হালকা আর পরিষ্কার দেখায়।
- **একটা চিকন টুলবার:** আগের দুই সারির বদলে একটাই 36dp চিকন সারি —
  টুলবারের বোতামগুলো সমতল (কীবোর্ডের ব্যাকগ্রাউন্ডের মতো, ধূসর বাক্স নয়)।
  শব্দের সাজেশন তার নিচে আলাদা সারিতে, মাঝখানে, নীল রংয়ে।
- **টুলবার আইকন-শুধু:** কোনো বোতামে লেখা নেই — Grammar Fix ✎, Tone 🎭,
  Clipboard 📋, Phrases 💬, Paste 📥, Undo ↩, Redo ↪, Settings ⚙️।
  সেটিংসে (৬. টুলবার) প্রতিটা আইটেমের টিক চিহ্ন দিয়ে দেখানো/লুকানো যায় আর
  Up / Down দিয়ে ক্রম বদলানো যায় — কীবোর্ডে শুধু দেখানো আইটেমগুলোই
  সেভ করা ক্রমে দেখাবে। ডিফল্টে সবগুলোই দেখানো থাকে। v2.2-এ ⚙️
  চাপলে কীবোর্ড থেকেই সেটিংস খুলে যায়।
- **স্পেসবার:** বড় "স্পেস" লেখার বদলে ছোট করে বর্তমান ভাষার নাম দেখায় —

- **নাম্বার সারি:** বাংলা সংখ্যার সারি আগের মতোই আছে, তবে চিকন —
  অন্যান্য সারির সমান উচ্চতা, সংখ্যার লেখা 18sp। সেটিংসে "Number row
  দেখান" বন্ধ করলে সারিটা লুকিয়ে যাবে, তখন দেখতে ঠিক Gboard-এর মতো হবে।
- **সীমা:** কি-গুলো GradientDrawable দিয়ে আঁকা হয়, তাই Gboard-এর মতো

  বাদ); কী না থাকলে আসল লেখাটাই বসে। কিছু শোনা না গেলে বা ভুল হলে
  টোস্ট দেখায়, অ্যাপ ক্র্যাশ করে না।
- **Gemini API কী (সেটিংসে)** — অ্যাপ ইনস্টল করার পরে

## Gemini API কী বসানো / বদলানো (ইনস্টলের পরে)

১. NexaKeyboard অ্যাপ খুলুন।
২. "২. Gemini API কী" অংশে কী-টা লিখুন।
৩. **Save / Update** চাপুন — নিচে "API key: saved" লেখা আসবে।
৪. বদলাতে চাইলে নতুন কী লিখে আবার **Save / Update** চাপুন।
৫. মুছতে চাইলে **Clear** চাপুন — "API key removed" দেখাবে।
৬. **Test** চাপলে কী-টা দিয়ে সত্যিই Gemini-কে ডাকা হয় ("Say OK"
   পাঠানো হয়)। সফল হলে "Test passed ✓ — Gemini is working"
   দেখাবে, ব্যর্থ হলে আসল কারণ দেখাবে (যেমন "Invalid API key",
   "No internet")। টেস্ট চলার সময় বোতাম বন্ধ থাকে।

কী ছাড়া ভয়েস টাইপিং, Grammar Fix আর Tone Change-এর AI অংশ চলবে
না — তখন "Gemini API key needed — set it in NexaKeyboard settings"
টোস্ট দেখাবে, আর ভয়েসের ক্ষেত্রে আসল লেখাটাই বসবে।

## ভয়েস টাইপিং ব্যবহার

১. বাংলা লিখতে চাইলে বাংলা মোডে, ইংরেজি চাইলে ইংরেজি মোডে যান।
২. টুলবারের উপরে ডানদিকের 🎤 বোতাম চাপুন, তারপর বলুন —
   সাজেশন বারে "🎤 শুনছি…" দেখাবে, আর বলার সময় শোনা কথাটা
   সরাসরি দেখাবে।
৩. থামলে Gemini কী থাকলে "AI ঠিক করছে…" দেখিয়ে লেখাটা পরিষ্কার
   করে বসবে; কী না থাকলে যেমন শোনা গেছে তেমনই বসবে। AI ব্যর্থ
   হলে আসল লেখাটাই বসে, কারণসহ জানিয়ে দেয়।

## APK বানানো (Android Studio দিয়ে)

১. Android Studio খুলে **Open** দিয়ে এই `NexaKeyboard` ফোল্ডারটা খুলুন।
২. প্রথমবার ইন্টারনেট লাগবে — Gradle আর Android SDK ডাউনলোড হবে।
৩. উপরে **Run ▶** চাপুন (ফোন USB দিয়ে লাগানো থাকলে) অথবা
   **Build → Build App Bundle(s) / APK(s) → Build APK(s)**।
৪. APK পাবেন `app/build/outputs/apk/debug/app-debug.apk`-এ।
৫. প্রথমবার ভয়েস টাইপিং ব্যবহারের সময় ফোন মাইক্রোফোনের অনুমতি চাইবে।

## ফোনে চালু করা

১. APK ইনস্টল করুন।
২. NexaKeyboard অ্যাপ খুলে **কীবোর্ড চালু করুন** চাপুন — সেটিংসে গিয়ে
   NexaKeyboard অন করুন।
৩. **কীবোর্ড বেছে নিন** চাপুন — তালিকা থেকে NexaKeyboard বেছে নিন।
৪. যেকোনো জায়গায় লিখে দেখুন।
